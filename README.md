# bloom-planner
Bloom Planner is a React-based Flower Event Scheduling and Management System. The application allows users to create, manage, organize, and track flower-related events such as festivals, exhibitions, weddings, and garden shows. It uses React Hooks, Context API, React Router, Protected Routes, Local Storage, and Error Boundaries to provide an interactive and user-friendly experience.
# Technoligies used
React.js, JavaScript, HTML5, CSS3, React Router DOM, Context API, Local Storage, GitHub, Netlify
